# 💕 Site de Pedido de Namoro


Um site simples, divertido e romântico criado para fazer aquele pedido especial de namoro de uma forma diferente. ❤️

A ideia é criar uma experiência leve e interativa: a pessoa se depara com a pergunta "Quer namorar comigo?", com duas opções: SIM e NÃO. Porém, o botão NÃO não facilita as coisas e foge pela tela sempre que alguém tenta tocá-lo. 😅

# ✨ Funcionalidades


💖 Interface romântica e responsiva

📱 Compatível com celulares

💻 Compatível com computadores

🖼️ Suporte para fotos personalizadas

❤️ Botão SIM interativo

🏃 Botão NÃO que foge pela tela

🎉 Tela especial após clicar em SIM

💕 Animação de corações

📐 Botão NÃO permanece dentro dos limites da tela

⚡ Projeto leve e sem necessidade de frameworks

# 🎨 Personalização


Você pode personalizar facilmente o site alterando:

💬 Texto do pedido

❤️ Mensagens da tela final

🖼️ Fotos

🎨 Cores

🔤 Fontes

✨ Animações

🔘 Textos dos botões


Para utilizar suas próprias imagens, coloque-as dentro da pasta imagens e altere os nomes dos arquivos no index.html.

# 🚀 Como executar


1. Faça o download ou clone este repositório.


2. Abra a pasta do projeto.


3. Certifique-se de que as imagens estão dentro da pasta imagens.


4. Abra o arquivo index.html em um navegador.


5. Faça o pedido. ❤️



# 💡 Ideia do projeto


O projeto foi criado para quem quer fazer um pedido de namoro de uma maneira simples, criativa e divertida, sem precisar de conhecimentos avançados em programação.

> Às vezes, um simples "quer namorar comigo?" pode virar uma memória inesquecível. ❤️
